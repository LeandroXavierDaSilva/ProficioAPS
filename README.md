## 🎯 Visão do Produto

Desenvolver uma plataforma web e mobile (**ProficioAPS**) para alunos e professores de disciplinas práticas acadêmicas até o final do semestre letivo (2026.1). 

A plataforma permitirá o mapeamento autônomo e contínuo de 100% das habilidades, experiências e repositórios do GitHub dos estudantes, fornecendo nivelamento automático assistido por IA e um dashboard em tempo real para os docentes. Espera-se reduzir em **40%** o tempo investido pelos professores no diagnóstico de lacunas técnicas e na formação de equipes de projeto nos primeiros três meses de uso.

* **🎯 Público-Alvo:** Alunos do ensino superior de tecnologia e professores/coordenadores de disciplinas baseadas em projetos (como APS).
* **🩹 Problema Resolvido:** Assimetria de informações sobre competências reais dos alunos, dificuldade dos docentes em diagnosticar o nível prático da turma e demora na composição de grupos equilibrados.
* **✨ Benefício Esperado:** Centralização do portfólio acadêmico do aluno integrado ao GitHub e tomada de decisão pedagógica baseada em dados analíticos em tempo real.
